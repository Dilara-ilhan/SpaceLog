MTA kodu ve proje geliştirme

MTA projesinde Java tabanlı çok servisli bir yapıyla ilgili kodlar üzerinde çalıştım. Gateway, kullanıcı kimliği ve bildirim servisleri gibi kavramlarla karşılaştım.

  • Servislerin birbirleriyle iletişimi
  • HTTP istekleri ve kimlik bilgilerinin aktarımı
  • Git ve GitHub ile kod takibi
  • Hata ayıklama ve yapılan değişiklikleri kontrol etme

Web geliştirme: SpaceLog

Ağ Tabanlı Programlama dersinde HTML ve temel CSS öğreniyorum. Bu siteyi her hafta öğrendiğim yeni konulara göre geliştireceğim.

Teknoloji Durum

MTA Yazılım Çalışmalarım

MTA projesindeki kodları incelerken farklı servislerin görevlerini ve birbirleriyle nasıl iletişim kurduklarını anlamaya çalışıyorum. Gateway, kullanıcı yönetimi, bildirim servisleri, hata ayıklama ve GitHub ile sürüm takibi gibi alanlarda deneyim kazandım.

SpaceLog projemde de artık JavaScript ile bir geri sayım sayacı ve tıklama olayları kullanıyorum.
