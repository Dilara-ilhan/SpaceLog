# SpaceLog

SpaceLog, Ağ Tabanlı Programlama dersi kapsamında geliştirdiğim kişisel uzay ve mühendislik web sitesidir.

## Projeyi Çalıştırma

1. GitHub deposundaki proje dosyalarını bilgisayarınıza indirin.
2. Proje klasörünü Visual Studio Code ile açın.
3. Live Server eklentisinin kurulu olduğundan emin olun.
4. `index.html` dosyasına sağ tıklayın.
5. **Open with Live Server** seçeneğine basın.

Web sitesi tarayıcıda açılacaktır.

## Kullanılan Teknolojiler

- HTML
- CSS

JavaScript de eklenecektir derste gördükçe.
